# About
This project aims to create a extensible framework for building a multi-protocol gateway for several protocols, mainly for IoT and industrial applications (CAN, Modbus, MQTT, etc.). It is written in C++17 and CMake for building.

## (targeted) Features

- **Protocol Agnostic**: Support for CAN, Modbus, MQTT, and more
- **Extensible Architecture**: Easy to add new protocol handlers, and interfaces
- **Real-time Data Processing**: Low latency communication
- **Industrial Protocols**: Built with factory automation in mind
- **Scalable Design**: Handle high throughput and concurrent connections
